# 考境哨兵 · ExamSentry

**安卓考试环境与防作弊行为检测工具。** 在手机本地记录应用切换、权限和环境变化，把实际观察到的事件关联为可复核时间线。

## 能做什么

- **持续监测**：指定考试应用和允许应用，记录离开、返回、可观察的前台应用及停留时长。
- **事件关联**：离开达到 3 秒、60 秒内反复返回、实测区返回后粘贴等规则，保留触发事件与来源。
- **环境变化**：建立权限、辅助服务、显示器、网络、VPN/代理、音频设备等基线，记录后续变化。
- **真实实测区**：原生模拟题、文本菜单观察和独立离线浏览器专区，覆盖操作、渲染参数、双页面与水印核验。
- **可选现场辅助**：CameraX + 随包 ML Kit 人脸检测；Silero VAD + ONNX Runtime 语音活动分析，默认关闭。
- **本地报告**：Room 存储；JSON 完整记录、PDF 时间线和 PNG 结果卡。PDF/PNG 分享时附同名 JSON。
- **记录核验**：事件摘要链、Android Keystore ECDSA 签名及公钥指纹，支持导入 JSON 核验。
- **原生界面**：Jetpack Compose、浅色/深色主题，以及总览、监测、实测、报告四个入口。

异常记录是复核线索。软件不输出未经校准的“作弊概率”，不自动对考生作出处罚结论。

## 使用方式

Android 8.0 / API 26 起可安装。无需账号或教师服务器。

1. 在“监测”选择考试应用与允许应用，按需授予使用情况访问；无障碍窗口信息为可选补充。
2. 点“开始监测”后进入指定考试应用。持续服务显示通知，结束时主动停止会话。
3. 需要验证本机检测时，在“实测”建立独立 LAB 会话，实际进行切屏、分屏、截图、粘贴等操作。
4. 相机、语音和画面保护由用户在实测区主动开启；相机与音频在离开前台时停止。
5. 在“报告”导出结果，并保留 PDF/PNG 随附的同名 JSON。

MONITOR 和 LAB 会话分别标记“监测”与“实测”，一次只运行一个会话。使用情况权限可能延迟或缺漏；无障碍只处理应用包名、窗口类型、边界和焦点等元数据，不遍历题目正文。

## 能力边界

| 项目 | 适用范围 |
|---|---|
| 截图 | Android 14+，本 App 可见时系统支持的截图方式；ADB 截图不能用于证明此回调有效 |
| 录屏 | Android 15+，系统回调报告本 App 是否在录制内容中可见；不扫描全机所有录屏 |
| 画面保护 | 请求 FLAG_SECURE，Android 12+ 另请求隐藏外部覆盖窗口；阻止截图后没有回调不能推断“未尝试” |
| 分屏、小窗 | 本 App 系统状态与可选无障碍可见窗口，不能覆盖所有厂商或隐藏窗口 |
| 复制、粘贴 | 内置文本菜单与离线页面实际事件；输入法直接插入、其他 App 内部操作不保证可见 |
| 其他应用权限 | 普通安装不能完整枚举其他 App 的悬浮窗、使用情况访问或录屏授权 |
| 音视频 | 本地人数估计和语音活动，不识别身份、说话人或作弊事实；不是活体检测 |
| 中断 | 强停后无法继续采集，下次启动记录中断；不能补造缺口期间的行为 |
| 报告签名 | 核验导出记录一致性，公钥来源需独立核对；不是硬件完整性证明 |

不能保证发现另一部手机拍摄、线下协助、系统隐藏行为或卸载后的操作。当前版本不提供教师服务器、设备管理员锁机或完整题库。

## 数据与网络

检测会话和统计保存在本机；应用不将原始相机画面、录音或剪贴板文本写入报告。

“在线网络检查”默认关闭。开启后仅由该功能请求 `https://api64.ipify.org?format=json`，在本机比较出口地址摘要，不发送检测事件或音视频。出口 IP 改变可能来自正常网络切换。

ML Kit 使用随包模型，移除自动初始化提供程序，用户开启视觉检测时才通过公开 API 初始化。Network Security Config 仅对 `api64.ipify.org` 配置系统公共根信任，其他标准 TLS 默认使用离线专用信任根，以抑制 SDK 诊断连接。此措施不覆盖所有原生自定义网络栈或外部系统服务，不能视为全机防火墙。详见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 源码构建

| 项目 | 配置 |
|---|---|
| 应用包名 | `cn.exam.sentry` |
| 最低 / 编译 / 目标 API | 26 / 36 / 36 |
| Android Build Tools | 36.0.0 |
| Gradle Wrapper | 8.13 |
| Android Gradle Plugin | 8.13.2 |
| Kotlin | 2.2.21 |
| Java / JVM 目标 | 17 |
| 界面 | Jetpack Compose / Material 3 |

准备 JDK 17 或受支持的新版本，安装 Android SDK API 36、Build Tools 36.0.0 和 platform-tools。在工程根目录创建本机 `local.properties`，配置 `sdk.dir`，然后执行：

```powershell
.\gradlew.bat assembleDebug
```

首次构建需要下载 Maven 依赖。Silero 模型已随源码提供，不需 API Key。正式发行须由维护者独立配置并保管签名材料；仓库不包含私钥、密码或服务凭据。升级已安装版本时，安装包签名必须匹配。
