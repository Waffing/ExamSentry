# 考境哨兵 0.2.0-preview 使用说明

作者：**Waffing** · [开源仓库](https://github.com/Waffing/ExamSentry) · [下载预览版](https://github.com/Waffing/ExamSentry/releases/tag/v0.2.0) · [联系作者](mailto:203458615@qq.com)

应用内版本为 `0.2.0`，发行标签为 `v0.2.0`。项目自有代码使用 MIT 许可；模型和第三方库各自的条款见《THIRD_PARTY_NOTICES》。

考境哨兵在安卓手机上记录考试应用切换、设备环境变化及可选现场辅助信号，提供时间线、关联异常和本地报告。异常记录供人工复核，不直接作出作弊结论。

## 安装与运行条件

- **真我 Neo8 / Android 16：[直接下载 ARM64 手机包](https://github.com/Waffing/ExamSentry/releases/download/v0.2.0/ExamSentry-0.2.0-arm64-v8a.apk)**，文件名为 `ExamSentry-0.2.0-arm64-v8a.apk`。`ExamSentry-0.2.0-x86.apk` 的处理器架构不适用，可能提示“安装失败”；改选正确包即可，无需因此卸载原有应用。
- Android 8.0（API 26）及以上可安装；截图回调需要 Android 14，录屏可见性回调需要 Android 15。
- 在发布页选择一个符合设备架构的 APK：大多数现代手机使用 `arm64-v8a`，仅支持 32 位 ARM 的旧设备使用 `armeabi-v7a`，x86 设备选择对应版本。各版本功能和随包模型相同，不需要安装四份。安装后从桌面打开“考境哨兵”。
- 需要持续监测时，允许通知权限，并按下文授权“使用情况访问”。无障碍、相机、麦克风均按需要开启。
- 默认关闭“在线网络检查”，无需注册账号或连接教师服务器；检测记录保存在本机。
- 打开 App 不会自动开始环境扫描或监测；点击总览“刷新状态”或主动开始会话时才检查。异常结束的旧会话仍会在启动时标记中断，这是记录恢复，不是新监测。
- 0.2.0 仅完成发布编译与签名，按要求未运行测试、Lint、模拟器或真机验收。此前的局部结果不代表新版本已复验，详见《功能覆盖与验收表》。

## 一、先选择监测方式

| 入口 | 用途 | 保存方式 |
|---|---|---|
| 监测 → 开始监测 | 观察指定考试应用的前台切换及设备环境变化 | 建立 MONITOR 会话，记录标记为“监测” |
| 实测 → 开始实测会话 | 在内置题目、文本区及浏览器专区验证真实动作是否被捕获 | 建立 LAB 会话，记录标记为“实测” |

一次只运行一个会话。切换方式前先结束当前会话。现场相机、语音和画面保护开关位于实测会话中；它们不会自动启用。

### 持续监测

1. 打开“监测”，填写会话名称。
2. 点“考试应用”选择要监测的 App；需要合法使用计算器等工具时，在“允许应用”中添加。
3. 点“使用情况访问”，在系统设置中允许“考境哨兵”访问使用情况，随后返回。
4. 需要跨应用窗口线索时，点“无障碍窗口信息”并在系统设置中手动开启。
5. 点“开始监测”，允许通知。进入指定考试应用后，系统才建立其离开与返回关系；停留在准备界面不算离开考试。
6. 考试结束后返回“监测”，点“结束会话”。也可使用常驻通知提供的结束操作。

使用情况访问能够提供应用事件，但可能有延迟或缺漏。未授权时可以观察本 App 的部分事件，跨应用检测范围会显示为“未授权”或“受限”。

无障碍服务只读取应用包名、窗口类型、边界和焦点等元数据，不遍历题目正文、不读密码、不采集其他 App 的截图。Android 的系统授权界面仍可能提示它具备较广能力，请按实际需要选择。

已允许应用不会触发非允许应用离开规则。输入法、系统窗口和从软件内发起的授权流程有单独处理；锁屏区间不据此前台记录推断应用行为。系统和厂商的窗口差异仍可能造成待复核线索。

### 规则与结果

- 离开指定考试应用达到 3 秒：记录待复核异常。
- 60 秒内至少 3 次离开并返回：记录重点复核线索。
- 在实测区返回后 10 秒内发生可观察的粘贴：关联离开、返回和粘贴事件，不保存粘贴内容。
- Root、模拟器、开发者选项、USB 调试、VPN 或耳机存在：属于设备环境线索，不单独等同作弊。

点击“总览”的异常可查看规则说明和关联事件编号；点击“监测”的事件可查看来源、时间与结构化细节。“有效探针”只表示当前接口可用，不代表检测到了某项作弊行为。

## 二、进行真实动作实测

在“实测”点“开始实测会话”后，可操作六科练习、文本区和浏览器专区。页面上的每条记录来自实际采集的事件。

### 六科答题与操作指引

- 内置语文、数学、英语、物理、化学、生物共 60 道原创选择题，每科 10 道，含答案解析，不依赖网络题库。
- 默认六科混合卷共 12 题，每科抽 2 题；可切换按科练习或重新组卷。未提交且已作答时，换卷需要确认。
- 支持上一题、下一题、答题卡跳转、已答进度、总用时、首答耗时与改答次数。切换底部入口或进入浏览器专项后返回，保留本次练习进度。
- 交卷后显示总分、分科结果和逐题解析。未答题计为未得分；练习成绩不用于判定作弊。记录包含题目编号、选项、耗时及操作类型，不保存文本区原文。
- “操作检测指引”列出 13 类真实动作，可展开查看操作步骤、探针状态及最近捕获事件的时间、来源和编号。只汇总最近 600 条事件，完整时间线请导出报告；“未观察到”不等于安全或动作失败，不支持和未授权单独显示。

| 动作 | 建议操作 | 查看位置与限制 |
|---|---|---|
| 切换应用 | 实测中切走超过 3 秒，再返回 | 事件时间线、关联异常；目的应用取决于授权和系统提供的事件 |
| 分屏、小窗 | 使用手机系统多窗口功能 | 本 App 多窗口探针；无障碍可补充可见窗口线索 |
| 原生复制、粘贴 | 长按内置文本区，使用系统文本菜单 | 只记录菜单动作与字符长度；输入法直接插入文本不一定触发粘贴回调 |
| 截图 | 关闭画面保护后，使用手机支持的物理按键截图 | Android 14+ 系统回调；ADB 截图不是此接口的验收方式 |
| 录屏 | Android 15+ 启动系统录屏，并使本 App 画面可见 | 本 App 被录制状态；不能证明其他 App 或全机没有录屏 |
| 窗口、键盘、旋转 | 弹起键盘、旋转手机、改变分屏尺寸 | 窗口尺寸、键盘和方向事件；尺寸变化本身不能证明作弊 |

“当前 App 画面保护”请求系统防截屏、录屏保护，并在支持的版本隐藏外部覆盖窗口。保护可能直接阻止截图或产生黑屏，因此没有截图回调不能证明用户没有尝试；软件也不会据此伪造一次“截图尝试”。

### 浏览器专项

点击“进入浏览器专项”打开独立全屏页面，左上角或系统返回可回到实测。页面直接滚动，日志预览为独立固定高度区域，最多显示 60 条，滚动停止后记录位置，避免持续新增日志拉动整页。

专区显示本地 Canvas 渲染摘要、WebGL 渲染器、WebRTC 本地候选和可视区。它不加载原网站，也不使用远程脚本；WebRTC 不配置 STUN 服务，只记录候选数量与私网地址暴露数量，不存地址。

- 点右上角加号打开对照页 B。两个真实页面通过同源消息互相发现；页面标签可切换。
- 点“复制水印样本”，在粘贴区实际粘贴，再点“核验输入水印”。只记录长度、是否匹配及本会话水印编号。
- 缩放、滚动、长按、选择及调试快捷键由页面的真实事件触发；手机版没有相关快捷键时无法验证该项。
- 分享图标生成当前浏览器专项结果卡。它是结果摘要，不是对任意泄题图片的自动追踪证明。

Canvas/WebGL 只帮助观察运行环境；WebView 渲染差异、软件渲染或指纹相同均不足以认定作弊。重复页面检测只覆盖本地同源同会话的这两个页面，不是全机多开扫描。

## 三、开启现场辅助

仅在实测会话中按需打开“视觉检测”或“语音活动”，并允许对应权限。切到后台、离开实测标签或结束会话时会停止分析；返回后需要主动重新开启。

| 项目 | 初始规则 | 解释 |
|---|---|---|
| 视觉检测 | 有效画面中无人脸持续 10 秒；多人脸持续 3 秒 | 本地 ML Kit 人数估计；不是身份核验或活体检测 |
| 语音活动 | 10 秒窗口内累计至少 5 秒语音活动 | 本地 Silero VAD；不识别说话人、不转写内容，电视、人声音乐也可能触发 |
| 画面质量 | 过暗、过曝或细节不足时暂停人数判断 | 不能覆盖所有模糊、遮挡及伪装情况 |
| 采集健康 | 相机断流、麦克风系统静音或读取失败 | 显示受限、过期或错误，不能作为“现场正常” |

原始画面与录音不由应用保存到文件，也不随报告上传。记录中保留人数、持续时间、模型概率和采集状态。ML Kit 在用户开启视觉检测时才初始化；应用网络安全配置仅对 ipify 开放系统 TLS 信任，以抑制其他标准 TLS 诊断请求。该配置不等于覆盖所有原生网络栈或外部系统服务的全机防火墙。第三方组件条款见《THIRD_PARTY_NOTICES》。

## 四、查看状态与报告

“总览”按项目显示：监测中、可用、受限、不支持、未授权、异常、数据过期和未开启。权限撤销、系统拒绝或采集停止都会降低覆盖范围。

进程被强停后无法继续采集。下次打开时，尚未正常结束的会话会标为“已中断”，依据最后心跳保留缺口记录；软件不会自动补造中断期间的行为。卸载或清除应用数据会丢失本机记录及原来的报告签名密钥。

本机只保留最近 **8 份会话**（监测与实测合计，包含正在运行的一份）。创建第 9 份时，最早会话及其事件、关联异常、覆盖快照一起删除；升级首次启动也会执行超额整理。保留会话的事件不会被截断，停止监测后在空闲阶段压缩数据库。自动过期的本机旧记录不提供恢复入口，请提前导出需要长期保留的报告。

App 临时目录仅保留最近 8 组报告导出（PDF/PNG 与同名 JSON 视为一组），另保留最近 8 张浏览器结果卡。JSON 校验使用的导入副本在完成后删除，异常遗留副本超过 24 小时清理。系统也可能自行回收缓存。清理不触及用户另存到下载目录、网盘等位置的文件。

在“报告”选择一个会话：

- **JSON**：完整事件、关联异常、覆盖快照、规则版本、摘要链和签名，是核验原件。
- **PDF**：便于阅读的摘要与时间线，分享时同时附同名 JSON。
- **PNG**：便于分享的结果卡，分享时同时附同名 JSON；结果卡不包含完整时间线。

在系统分享菜单中选择保存位置或接收应用。请把 PDF/PNG 与其同名 JSON 一起保留。导出进行中的会话只反映导出时刻已有记录；完整复核应在结束会话后再次导出。

“校验已导出的 JSON”检查内容摘要、事件序号与摘要链，以及 ECDSA 数字签名。核验通过说明文件与其签名一致；核对设备来源还需独立比对公钥指纹。报告自带的公钥、有效签名和本地 Keystore 均不是硬件远程证明，不能证明手机从未被篡改或日志覆盖了所有行为。

## 五、在线网络检查

默认关闭。开启时，App 向 `https://api64.ipify.org?format=json` 发起 HTTPS 请求获取出口 IP，在本机比较其摘要。检测事件、应用路径及音视频不会由此接口发送到 ipify。ipify 作为接收请求的服务会看到出口地址。

出口地址变化可能来自 Wi-Fi 与移动数据切换、运营商或 VPN，不单独认定作弊。请求失败时标记检查不可用，不填入一个“正常”结果。

## 六、无法完整检测的情况

普通安装的安卓应用无法完整枚举其他 App 的悬浮窗、使用情况访问和录屏授权，无法读取它们全部内部答题、剪贴板或屏幕行为。它也不能发现所有隐藏覆盖层、另一部手机拍摄、线下协助或被卸载后的操作。

此版本不建设教师后台、不自动封禁考生，也不提供设备管理员锁机功能。使用本机报告作正式判断前，需要结合具体考试规则和现场复核。

## 七、源码构建与维护

工程为 `ExamSentry`，应用包名 `cn.exam.sentry`。固定配置：最低 API 26，编译及目标 API 36，Build Tools 36.0.0，JVM 目标 17，Gradle 8.13，AGP 8.13.2，Kotlin 2.2.21。

安装 JDK 17 或受支持的新版本，并在 `local.properties` 设置本机 Android SDK 路径，例如 `sdk.dir=D\:\\Android\\Sdk`。SDK 需要 `platforms;android-36`、`build-tools;36.0.0` 和 `platform-tools`。在工程目录执行：

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest
.\gradlew.bat connectedDebugAndroidTest
```

第二条需要已连接的测试设备。独立浏览器水印检查：

```powershell
node --check .\app\src\main\assets\lab\lab.js
node --test .\app\src\main\assets\lab\watermark.test.cjs
```

正式更新需沿用原发行签名；本地重新生成签名的安装包不能覆盖签名不同的旧版本。签名私钥和密码不应写入源码或交付文档。

## 八、持续运行验收脚本

开发工作区的 `work/validation/soak.ps1` 默认采样 60 分钟，每 30 秒保存本应用的内存、CPU、前台监测服务状态，以及设备电量、温度。本次未执行该 60 分钟验收；下面命令仅供之后维护时参考。先连接指定测试设备并手动开始监测，再执行：

```powershell
pwsh -File .\work\validation\soak.ps1
```

可用 `-AdbPath`、`-Port`、`-Device`、`-Package`、`-DurationMinutes`、`-OutputDirectory` 指定环境。默认端口为 5038，目标为 `127.0.0.1:16384`，对应当前测试用模拟器配置。

脚本生成 JSONL 样本与 summary JSON，不保存 dumpsys 原文、其他应用列表、设备序列号、音视频或答题内容。缺失指标为 `null`，不是通过。它不能单独验证事件连续性或检测准确率，还需核对会话心跳和导出的摘要链。模拟器的温度、电量及耗电数据不能代表实体手机续航。
