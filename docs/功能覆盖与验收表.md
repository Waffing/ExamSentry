## 状态说明

- **已实现，待设备验收**：已有实际 API 或本地算法路径，仍需在目标设备执行相应动作。
- **受限**：只能观察所列局部信号，结果不代表全机或全部软件。
- **不提供**：当前版本无该能力，或普通安卓权限无法完整实现。
- **本地检查通过**：只适用于本表明确列出的代码级或模型级检查。

## 判读限制

软件提供自动采集事实和本地规则线索，不保证捕获所有作弊方式。另一台设备拍摄、不可见系统行为、隐藏或被篡改的进程，以及卸载后的操作不在完整覆盖范围内。签名有效不等于设备可信，探针可用不等于考试环境无作弊。
